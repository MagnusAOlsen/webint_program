# WineLover
The main goal of the app is to create a space where users can share reviews and
opinions about different wines, making it easier for others to find options that suit
their taste.

Users should easily be able to find a wine they are thinking of, whether they have
had it before or not.

Our functionalities:

- Wine search
    - Users can find new wines based on various filters
    - Users can search for specific restaurant names to see their wine list
- Wine reviews
    - Once a user has tried a wine, he/she can post a review of that specific wine
- Wine database
    - User can keep track of various wines they have consumed and notes on each wine
- User profile page
    - User can update their own profile page with user details and their own personal quote
